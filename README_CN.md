# HG-FBG 本地监控软件（中文版说明）

本项目是一个本地部署的分布式光纤测温监控软件，包含：
- C++ 内核：`native/`（封装 SDK，输出 `dts_core.dll`）
- C# WPF 界面：`managed/DtsMonitor.App/`

> 适用 SDK：`D:\WorkSpace\DTS\DTS SDK V1.0 20250625\interface.h` 对应的 `RC_FBGSystem.dll`

---

## 1. 控制页参数说明（你问的“这些参数干什么用”）

### 采集基础参数

1. `设备 IP`
- 含义：真实设备的网络地址。
- 作用：点击“连接设备”时用于 SDK 初始化（`DTS_Initialize`）。

2. `通道号`
- 含义：采集通道编号。
- 作用：用于波长配置、通道配置、校准、开始/停止运行。
- 备注：当前软件默认 `0`；若你的硬件手册要求从 `1` 开始，请按设备文档填写。

3. `起始波长(nm)` / `截止波长(nm)`
- 含义：采集光谱范围。
- 作用：下发到 `RCSystem_SetParamInfo(start, stop, fiberLength)`。
- 约束：`起始 < 截止`，否则下发失败。

4. `光纤长度(m)`
- 含义：被监测光纤总长度。
- 作用：用于距离轴重建、地图位置映射、自动计算重建点数。

5. `采样间隔(m)`
- 含义：距离方向的采样步长。
- 作用：自动计算重建点数：`重建点数 = 光纤长度 / 采样间隔 + 1`。

6. `重建点数(自动)`
- 含义：重建温度剖面的点数。
- 作用：传给内核 `target_profile_points`，用于插值重建。
- 备注：界面只读，由“光纤长度+采样间隔”自动生成。

7. `延时(ns)`
- 含义：采集延时。
- 作用：下发 `RCSystem_SetDelay`。

8. `脉宽`
- 含义：激光脉冲宽度。
- 作用：下发 `RCSystem_Setplusewidth`。

### 算法与报警参数

1. `报警阈值(C)`
- 含义：温度报警门限。
- 作用：温度超过此值会生成报警点；等级规则为：
  - 低：`>= 阈值`
  - 中：`>= 阈值 + 5`
  - 高：`>= 阈值 + 10`

2. `传感器数量`
- 含义：传感点数量。
- 作用：自动生成传感器位置（均匀分布）和波长索引映射。

3. `速度模式(0-3)`
- 含义：运行速度模式。
- 作用：透传到 `RCSystem_SetFBSpeed`。
- 备注：SDK 注释常见 `0=低速,1=高速`，`2/3` 需以设备型号文档为准。

4. `激光器模式`
- 含义：激光运行模式。
- 作用：透传到 `RCSystem_SetLaserType`。

5. `算法模式`
- 含义：测温/解算模式。
- 作用：透传到 `RCSystem_SetAlgothrimType`。

6. `中心波长列表`
- 含义：多波长中心点（逗号分隔）。
- 作用：透传到 `RCSystem_SetMutilWaveInfo + RCSystem_SetMutilWaveDataInfo`。
- 示例：`1532,1542,1552`

## 2. 如何连接真实设备进行测试（实操步骤）

## 2.1 前置检查

1. 物理与网络
- 设备上电，网线接通；
- PC 与设备在同网段；
- 先 `ping 设备IP` 确认可达。

2. 运行依赖（必须在 EXE 同目录）
- `dts_core.dll`
- `RC_FBGSystem.dll`
- `opencv_world3412.dll`

3. WebView2 Runtime
- 地图页面依赖 WebView2，建议已安装最新版 Runtime。

## 2.2 启动与连接流程

1. 启动程序。
2. **取消勾选** `仿真模式(无设备)`。
3. 在“控制”页填写参数（至少 IP、通道、波长范围、光纤长度）。
4. 点击顶部 `连接设备`。
5. 点击顶部 `下发配置`。
6. 可选：点击 `开始校准`，完成后 `停止校准`。
7. 点击 `开始运行`，进入实时采集。
8. 到“监控”页查看波形、报警点与状态更新。

## 2.3 停止流程

1. 点击 `停止运行`。
2. 需要时再 `停止校准`。
3. 关闭程序。

## 4. 常见问题排查

1. 连接失败（`rc != 0`）
- 检查 IP 与网段；
- 检查设备是否已被其他程序占用；
- 检查 `RC_FBGSystem.dll` 是否正确放在输出目录；
- 查看界面提示中的 `error=...`。

2. “下发配置失败”
- 检查起止波长：必须 `Start < Stop`；
- 光纤长度需 > 0；
- 中心波长列表格式要正确（逗号分隔数字）。

3. 能连接但无实时数据
- 确认已点击 `开始运行`；
- 检查通道号与实际通道一致；
- 先做一次校准再运行；
- 检查设备本体是否有有效回波数据。

4. 地图页面样式更新后看不到变化
- 先彻底关闭程序再重开；
- 必要时删除 WebView2 缓存目录：
  - `managed\DtsMonitor.App\bin\Release\net10.0-windows\HG-FBG.exe.WebView2`

---

## 5. 重要说明

1. 当前内核温度换算仍是占位模型（用于联调）：
- `Temp = 25 + (wavelength - baseline) * 120`
- 后续应替换为设备厂家提供的正式温度解算模型。

2. 若现场确认 SDK 通道号确实从 1 开始，建议统一梳理 UI 和内核通道编号规则，避免错配。
